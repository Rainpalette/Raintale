## 3. Why / 为什么这样分开授权

This mirrors how projects like Firefox separate open-source code from protected brand assets. It gives teeth to the project's **three-tier character stance** (see README / worldview):

- **Official characters** ship only in official builds — because forks cannot legally bundle the Official Assets.
- Anyone may fork the **MIT-licensed code**, but a fork that ships its own characters does so **without** the Official Assets, and is **not** endorsed by this project.

代码可自由 fork（MIT），但官方立绘/形象不随之开放——**非官方构建无权打包官方资产**。这样"非官方角色与本项目无关、使用者自负"的立场才站得住。
