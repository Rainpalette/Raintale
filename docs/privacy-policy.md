# 雨中逸事（Rain Tales）隐私政策

> **最后更新：2026-07-07**
> 适用于《雨中逸事 · Rain Tales》（工程名 FirstVR，原开发代号 PhotoBuddy）。本文用通俗中文说明 app 怎么处理你的数据。
> 当前为**原型 / debug 阶段**：客户端直连、未接后端代理与计费，正式发布前本政策会再更新。
>
> **年龄要求：** 本应用的 AI 功能使用你自己的第三方 AI 账号（Google Gemini），依其条款，使用者须**年满 18 岁**，或达到你所在地区法定的成年 / 数字同意年龄。

---

## 一句话总则

**PhotoBuddy 不收集、不上传、不向开发者回传你的任何数据。** app 本体只把数据存在你自己的手机上。只有当你**主动开启**相应功能时，部分数据才会**用你自己的账号**发给第三方（Google Gemini、维基百科）以完成该功能——发什么、何时发、发给谁，下面逐条说明，并且**都能在设置里关掉**。

---

## 1. 只存在你手机上的数据（永不外发）

| 数据 | 存在哪 | 说明 |
|------|--------|------|
| 你拍的照片 / 合照 | 系统相册 `Pictures/PhotoBuddy` | 和普通相机一样存进你的图库，由你掌控。 |
| 你的 Gemini API Key | app 私有存储（DataStore） | 仅用于直接调用**你自己的** Google 账号。app 不收集、不上传、不回传给开发者。可随时在设置里清除。 |
| 设置项 | app 私有存储（DataStore） | 各开关偏好，仅本机。 |
| 影集批注 / 照片元数据 | app 私有存储（本地数据库） | 角色说的话 + 你写的批注 + 是否最爱等，仅本机。可在设置里**导出成文件**备份、或导入恢复（见下）。 |
| 调试日志 | 仅运行时内存 | 「开发者」页可见，重启即清，不外发。 |
| 崩溃报告 | app 私有存储（本地文件） | 万一 app 崩溃，会把错误堆栈 + 设备/版本信息**存在本机**，下次启动时提示你查看或分享。**仅存本机、不自动上传**，是否分享由你决定（其中的 API key 已自动打码）。 |

这些数据**开发者完全看不到**。

> **已关闭系统云备份：** 为确保上表"只存本机"的承诺严格成立，本应用**关闭了 Android 的自动云备份**——你的 API key、设置、批注都不会随系统备份上传到 Google。代价是：卸载重装 / 换机时这些数据不会自动回来，需用下方的**导出 / 导入**手动备份。

**回忆的导出 / 导入（可选、由你操作）：** 设置 → 隐私 → 「回忆备份」可把影集批注 + 照片元数据**导出成一个 JSON 文件**，或从这样的文件**导入**恢复。文件存到**哪里由你在系统文件选择器里指定**（app 不替你决定、不上传任何服务器）。导出的文件里**不含你的 API key**，只有批注与元数据。之后这个文件怎么保管、发给谁，由你自己负责。

## 2. AI 评论 → Google Gemini（云端，可关）

**仅当**你开启「AI 评论」**且**配置了 API Key 时，拍照后才会发生网络请求。**经你自己的 API Key**，以下内容会发送到 Google Gemini：

- 📷 **你拍的合照**（上传前已自动缩小到最长边约 1024px）；
- 📍 **大致位置**（城市/地区级**地名**，不是精确经纬度）——仅当「位置信息」开启；
- 🕐 **当前时段**（如"早上"）——仅当「时段信息」开启；
- 💬 **你输入的留言**——仅当你使用「留言拍照」并填写留言时；
- 角色的动作、性格设定与任务指令（这些不是你的个人数据）。

**重要提示：**
- 请求走的是**你自己的** API Key，数据直达**你自己的 Google 账号**，开发者不经手、看不到。
- 你需自行遵守并参考 [Google API 服务条款](https://ai.google.dev/gemini-api/terms) 与 [Google 隐私政策](https://policies.google.com/privacy)。
- ⚠️ **免费版 Gemini plan 的内容可能被 Google 用于改进其模型（训练）。** 若介意，请在 Google 一侧使用**付费 plan**（付费版默认不用于训练），并尽量少开下面的可选信息。
- 关闭「AI 评论」后，拍照**完全不联网**，照片只存本机。

---

## 3. 按 AI 方式划分的隐私程度

你的隐私"暴露多少"取决于 AI 用哪种方式运行：

| AI 方式 | 照片是否离开设备 | 隐私程度 | 状态 |
|---------|------------------|----------|------|
| **关闭 AI** | 否，完全不联网 | **最高** | 已实现 |
| **云端 API（Gemini）** | 是，发给你自己的 Google 账号 | 中（取决于你开了哪些可选信息） | 已实现 |
| **端上模型（设备本地 LLM，如 Gemini Nano）** | 否，生成在设备本地完成 | 高 | **尚未提供**，仅在未来支持的旗舰设备上作为可选项；届时本政策会更新 |

> 端上模型目前并未实现，仅作为未来方向列出；现阶段开启 AI 即为"云端 API"方式。

---

## 4. 知识链接 → 维基百科（可关）

**仅当**你开启「知识链接」**且**画面里识别到值得查的实体（地标/品牌/知名作品等）时，app 会向维基百科查询简介。此时发送给维基的**只有实体的名字 + 你的系统语言**。

- 简介内容来自**维基百科官方接口**（权威源，非 AI 编造）。
- **不会**把你的位置坐标发给维基——同名地点的消歧义是在**你手机本地**用坐标挑出最近候选，坐标不出设备。
- 关闭「知识链接」后，不会发生此类请求。

---

## 5. 端上感知（ML Kit 人像分割）

「人像模式」用 **ML Kit** 把人从背景里抠出来做"人在前/人在后"分层。该处理**完全在你的设备本地运行**，相关画面/照片**不上传任何服务器**。

---

## 6. 位置信息

- app 仅申请**粗略位置**权限（`ACCESS_COARSE_LOCATION`），不获取精确 GPS。
- 取得的坐标经系统服务反向地理编码成**区域级地名**（城市/地区，不含街道）。
- app 本身只会把**地名**（而非坐标）随 AI 请求发出，且仅在「位置信息」开启时。
- 「位置信息」**默认关闭**，可随时开关；设置页可查看当前识别到的粗略地名以便核对。

---

## 7. 在设置里调整你的隐私程度

你可以在 **设置 → 隐私 / AI 与评论** 等分类下自行权衡。常用开关与默认值：

| 设置 | 作用 | 默认 |
|------|------|------|
| AI 评论 | 关闭则只拍照、完全不联网 | 开 |
| 位置信息 | 是否把大致地名发给 AI | **关** |
| 时段信息 | 是否把当前时段发给 AI（情境参考） | **关** |
| 知识链接 | 是否向维基查询实体简介 | **关** |
| 账户 / BYOK | 填你自己的 Gemini Key | 未配置 |

设置页还提供「**隐私程度概览**」，会按你当前的开关实时显示"哪些信息会离开设备"。

> **权衡说明：** 关掉位置、时段、留言等信息更护隐私，但 AI 缺少这些上下文时，回复可能**不那么应景、不那么准确**（例如分不清你在哪个城市、不知道是早是晚）。隐私与"回复贴合度"是此消彼长的，由你按需取舍。

## 8. 数据共享与出售

- 开发者**不收集**你的数据，因而**不会出售、不会共享**给任何第三方用于广告或分析。
- 唯一的数据外发，是上文所述"由你开启的功能、用你自己的账号"直连 Google / 维基——这属于**你与那些服务之间**的关系，请参考它们各自的条款。

---

## 9. 变更与联系

- 本政策随功能演进更新，更新会修改顶部"最后更新"日期。
- **联系方式**：问题与反馈请通过 GitHub Issues 提出——https://github.com/Rainpalette/raintale/issues （注意：issue 内容公开可见，请勿贴出你的 API key 或个人信息；Debug 页与崩溃报告已自动为 key 打码）。
- app 内查看本政策：设置 → 关于 → 隐私政策。
