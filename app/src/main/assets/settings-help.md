## 二、每个设定是干嘛的

**AI 与评论**
- **AI 评论**（默认开）：关掉后按快门只拍照存相册、完全不调用 AI、不联网。
- **知识链接**（默认开）：评论里若识别到地标/品牌等专有实体，会挂一个「了解」入口，点开看维基简介。通用物体（书架、杯子）不会挂。

**语音**
- **朗读评论 (TTS)**（默认开）：出评论时用**系统语音**念出来（设备自带、离线、不联网）。关掉只显示文字。音色由系统语音引擎决定，app 内不可调；角色专属音色未实现。

**隐私**
- **位置信息**（默认关）：开启会把**大致位置**（城市/区域级，不是精确坐标）发给 AI，让回复更应景。**会拖慢回复**（要反向地理编码）。
- **时段信息**（默认关）：开启会把当前时段（早上/晚上…）发给 AI 当情境参考（不会强制问候）。
- **隐私概览**：按当前开关实时算出"什么会离开你的设备"。
- 说明：ML Kit 人像分割在**本机**运行，从不上传。

**拍摄**
- **画面比例**：`4:3` / `16:9`（居中、上下留黑边、拍标准比例）/ `全屏`（满屏裁切）。实时点评固定全屏。
- **屏幕方向**：`自动`（照片方向随手机倾斜，横拿出横图）/ `锁定直屏` / `锁定横屏`（锁定后方向固定、不随倾斜变）。

**实时点评**
- **录影**（默认开）：开始点评时同步录屏；录制中「停止点评」和「拍照」按钮会隐藏（点原位置仍有效）。关掉则只点评、不录屏。
- **短时记忆**（默认关）：记住最近的 AI 评论（**最多 10 条 / 1 小时**）当额外上下文，让点评更连贯、少重复。关掉则每句只看当前画面。
- **抓帧间隔**（默认 12 秒）：**多久"看一眼"画面说一句**。想让角色说话更勤=调小（如 5 秒），想安静点/更省额度=调大（预设到 10 分钟）。
- **静止处理**：画面**没变化**时怎么办——`跳过`（安静省额度，默认）/ `静止循环`（连续静止几次出一句陪伴的环境语音）/ `直接再发`（照样评论）。

**人像拍照**
- **高帧率 (30fps)**（默认关）：人像模式的实时抠图帧率。开=减残影、更耗电；关=12fps。

**角色**
- **角色条**（默认显示）：展开工具条时是否显示"切换角色"那一条。
- **默认展开角色/动作条**（默认关）：开=进相机时工具条直接展开、不带收起把手；关=默认收起、点把手才展开（取景更干净）。

**账户 / BYOK**
- 填你**自己的** Gemini API key（到 aistudio.google.com 免费申请）。key 只存本机、不上传。没填且没内置 key 时，AI 评论用不了。

## 三、"我想要 X" → 去调哪里（常见诉求速查）

- **实时点评说话太频繁 / 太少** → 「实时点评→抓帧间隔」调整（默认 12 秒，调小说话更勤、调大更安静）。画面不动时说不说另由「静止处理」控制。
- **角色不说话 / 没声音** → 确认「朗读评论 (TTS)」开着、「AI 评论」开着、有网、账户里填了 key。若设备缺中文 TTS 语音数据，要去系统设置装。
- **想要不一样 / 更好的嗓音** → app 内**不可调**：朗读用的是系统语音引擎，换嗓音要去**系统设置**里换 TTS 引擎或语音包。角色专属音色**未实现**。
- **AI 回复太慢** → 关「位置信息」（它要反向地理编码，最拖时间）。
- **不想让照片/信息发出去（隐私顾虑）** → 关「AI 评论」（完全不联网）；或看「隐私→隐私概览」确认发了什么。位置/时段默认就是关的。
- **实时点评老是重复同样的话** → 开「短时记忆」。
- **画面不动时不想让它一直说话 / 想让它偶尔陪一句** → 「实时点评→静止处理」：不想说选「跳过」，想偶尔陪一句选「静止循环」。
- **拍出来的照片比例不对 / 太长** → 「拍摄→画面比例」选 4:3 或 16:9。
- **横拿拍出来方向乱 / 想固定方向** → 「拍摄→屏幕方向」：想跟手用「自动」，想固定用「锁定直屏/横屏」。
- **取景界面太乱 / 工具条挡视线** → 「角色→默认展开」关掉（默认收起）；不需要切角色可关「角色条」。
- **人被角色挡住了 / 想让人站在角色前面** → 用底部「人像」模式，切「人在前」。
- **没有 AI 评论、提示"未配置 key"** → 「账户 / BYOK」填你自己的 Gemini key。
- **我是来测试 AI 有没有 prompt 防护的** → 尽管测，随便戳。用的是**你自己的 key 和额度**，戳坏了也是你自己的事，我们不心疼 😌。
- **录影每次都要授权，好烦** → 这是 Android 的安全机制，录屏授权无法一次永久，每次开录都会弹。（已帮你默认成"整个屏幕"，少点一步。）
- **返回键行为** → 现在返回键是"逐层往回退"（关面板 → 退子页 → 退回普通模式），退无可退才问你是否退出，不会一下子退出 app。

## 四、暂时还不能调（规划中，别指给用户）

> 这些是用户可能会问、但目前**没有对应设定**的。设定助手遇到应**如实说"暂不可调"**，别编一个不存在的开关。（同时提醒作者：这些是值得补的设定。）

- **画面变化灵敏度**：固定"中"，不可调。
- **语音最小间隔 / TTS 重叠策略**：未做。
- **回复文字/语音语言**：跟随系统，未做多语言设定。
- **角色专属克隆音色**：未做。曾实验过端上神经语音（sherpa-onnx），已于 2026-11 下架；现在只有系统 TTS。
- **app 内新增/编辑角色**：规划中，暂时只能改代码加角色（见项目 README「加一个新角色」）。
- **修图**：拍后面板的「修改」目前是占位（敬请期待）。
